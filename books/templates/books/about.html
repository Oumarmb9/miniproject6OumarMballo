About BookNook

BookNook is a small Django web application built for INF601 – Advanced Programming in Python (Mini Project 6). It demonstrates a complete, database-backed web app with user accounts and a styled admin.

What it does

  • Lets you register and log in securely using Django's authentication system.
  • Gives each user a private bookshelf stored in a SQLite database.
  • Supports adding, editing, and deleting books with a genre, status, rating, and notes.
  • Provides a styled Django admin for managing books and genres.

How it's built

  • Django — project/app structure, models, views, templates, and admin.
  • SQLite — the database, with two models linked by a foreign key (Book → Genre, Book → User).
  • Django auth — the register / login / logout system.
  • Bootstrap 5 — responsive styling and the delete-confirmation modal.
